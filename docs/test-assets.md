# External waveform test assets

> Status: regression input inventory · downloaded 2026-09-04 · hashes verified 2026-09-05

These assets let DecodeHub exercise real and generated protocol traffic
offline. `tests/unit/test_external_asset_manifest.py` protects the published
files against accidental byte changes. Decoder integration assertions are
added with the corresponding adapter or protocol feature.

them in the sibling development repository and skip when unavailable.
